# Simple Python Calculator

## Description
A beginner-friendly command-line calculator built with Python 3.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Invalid number handling
- Invalid operator handling

## Requirements
- Python 3

## How to Run

Open a terminal and run:

python3 calculator.py

## Example

Enter first number: 10
Enter operator (+, -, *, /): +
Enter second number: 5

Result: 15.0

## Technologies
- Python 3
